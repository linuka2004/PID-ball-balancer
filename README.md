# PID-Based Ball Balancer

A ball-on-beam position control prototype that uses sensor feedback
and servo actuation to maintain a ball at a target position.

## Features

- Closed-loop PID position control
- Distance sensor feedback
- Servo-driven beam adjustment
- System modelling and simulation using MATLAB/Simulink
- Experimental evaluation of controller performance

## Project Files

- `firmware/` — Microcontroller source code
- `simulation/` — MATLAB scripts and Simulink models
- `images/` — Prototype and component photographs
- `docs/` — Project documentation and schematics
